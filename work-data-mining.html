05 / DATA MINING

Predicting Server Failures

Failure classification and resource hotspot analysis

ROLE
Team member & report co-author
CONTEXT
CSC 240 Data Mining · University of Rochester
STATUS
Course project · Spring 2026

Project overview

Which signals help flag tasks at risk of failure before they run, and which patterns help explain failures during execution? Our team analyzed 405,894 data-center task records to investigate both questions.

Team approach

  • We turned raw resource records into CPU and memory features and cleaned the data before modeling.
  • We compared classification models and used FP-Growth to find combinations of conditions associated with failure.
  • We compared features known before a task starts with features measured during execution to distinguish early warning signals from patterns useful for diagnosis.

Team outcome

Scheduling class showed a modest association with failure before execution. During execution, high CPU pressure paired with low peak CPU or memory levels was more strongly associated with failure. These patterns suggest what operators could monitor while a task is running.
